### ☕ About Me

<img align="right" alt="Coding" width="380" src="https://raw.githubusercontent.com/devSouvik/devSouvik/master/gif3.gif">

I'm a **Java Full-Stack Developer** who builds enterprise-grade backends and modern frontends — and also tinkers with **on-device GenAI**. I care about clean architecture, readable code, and shipping things that actually work in production.

- 🎯 **Core Stack:** Java 17+, Spring Boot, Hibernate/JPA, Next.js, React, TypeScript
- 📱 **Mobile:** Flutter — including on-device/offline AI apps (GGUF models, llama.cpp bindings)
- 🧠 **GenAI:** Prompt engineering, RAG pipelines, on-device inference, ChatML formatting
- 🏗️ **Backend:** RESTful APIs, Microservices, Event-Driven Architecture (Kafka)
- 🗄️ **Databases:** PostgreSQL, MySQL, MongoDB, Redis
- ☁️ **DevOps/Cloud:** Docker, Kubernetes, AWS, Jenkins, GitHub Actions, Nginx
- 🌱 **Currently Exploring:** Spring WebFlux, Reactive Programming, System Design at scale
